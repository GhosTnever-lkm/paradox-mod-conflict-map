КАРТА ПЕРЕСЕЧЕНИЙ

Добавь ZIP или папки модов

Порядок сверху вниз: нижние моды условно перекрывают файлы верхних, если игра обрабатывает одинаковые пути по этому правилу.

Можно выбрать папку мода или несколько модов. Без descriptor.mod приложение использует выбранную папку целиком.

    КАК ЧИТАТЬ РЕЗУЛЬТАТ

    Пересечение — повод
    проверить, а не паниковать.

    Одинаковый относительный путь в нескольких ZIP может означать, что один мод заменяет файл другого. Это не доказывает несовместимость: игра, формат данных и намеренные патчи влияют на результат.

    01

    Путь совпадает

    В отчёт попадают одинаковые пути файлов после нормализации регистра и разделителей.

    02

    Порядок важен

    Отчёт показывает выбранный порядок и последний архив в списке. Фактические правила игры могут отличаться.

    03

    Содержимое не читается

    Приложение сравнивает метаданные ZIP. Оно не проверяет код, семантику файлов, зависимости и ошибки игры.

    ⛨

    Файлы остаются на твоём устройстве

    Для папок приложение читает только относительные пути и размеры выбранных файлов; из ZIP — центральный каталог. Содержимое файлов не отправляется на сервер, сами архивы не распаковываются.
